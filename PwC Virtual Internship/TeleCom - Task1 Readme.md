Telecom Call Center Dashboard - Power BI
Project Overview:
This project involves creating a Power BI dashboard tailored for Claire, providing a comprehensive view of the Telecom Call Center's performance. The dashboard focuses on key performance indicators (KPIs) and metrics that reflect customer satisfaction, call handling efficiency, and agent performance. The goal is to offer actionable insights to improve overall call center operations.

Dataset Information:
The dataset includes detailed call records, agent performance metrics, customer satisfaction ratings, and time-based data. Key attributes include call status (answered, abandoned), call duration, time of call, customer feedback, and agent-specific performance data.

Key Objectives:

Enhance Customer Satisfaction: Monitor overall customer satisfaction to identify trends and areas for improvement.
Analyze Call Handling Efficiency: Track metrics related to calls answered, abandoned calls, and average speed of answer to ensure efficient call handling.
Evaluate Agent Performance: Assess agent performance using a performance quadrant that compares average handle time (talk duration) against the number of calls answered.
Time-Based Call Analysis: Examine call volumes and patterns based on time to optimize staffing and resource allocation.
Problem Statement:
The Telecom Call Center Dashboard aims to address the following business challenges:

Customer Satisfaction Trends: How is overall customer satisfaction trending, and what factors are influencing it?
Call Handling Efficiency: Are calls being answered in a timely manner, and how many are being abandoned?
Agent Performance Evaluation: Which agents are performing well, and where is there room for improvement?
Time-Based Call Analysis: When are the peak times for calls, and how can resources be better allocated?
Dashboard Features:

Overall Customer Satisfaction: A visual representation of the customer satisfaction score, showing trends over time.
Overall Calls Answered/Abandoned: A KPI visual displaying the total number of calls answered versus those abandoned.
Calls by Time: A time-based analysis showing call volumes during different times of the day/week.
Average Speed of Answer: A KPI visual tracking the average time it takes to answer a call.
Agent Performance Quadrant: A scatter plot or quadrant chart comparing agents' average handle time with the number of calls they answered, helping to identify top performers and those needing improvement.
